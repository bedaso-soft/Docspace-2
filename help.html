Welcome to DocSpace Help. Here you’ll find answers to common questions and guidance on how to use the platform effectively.

Getting Started

  • Create categories to organize your documents.
  • Click on a category to add or view documents.
  • Use search to quickly find documents.

Managing Categories

  • Rename categories by clicking the edit icon.
  • Delete categories using the delete button.
  • Changes are saved automatically.
